## 第一条 定义与文件效力

1. “开源软件”指依据 Apache License 2.0 发布的 Supply Chain Expert 公共仓库内容。
2. “企业服务”指本协议及附件明确约定的部署、配置、定制、集成、培训、维护和支持。
3. “客户数据”指甲方提供或在服务过程中产生的采购清单、报价、供应商、合同、账号、日志、知识库及其他业务数据。
4. 本协议、订单、项目范围说明书、数据处理附件和验收单共同构成完整约定。冲突时按双方在订单中约定的优先顺序执行。

4. 双方各指定一名项目负责人；影响范围、费用或周期的决定须书面确认。

## 第五条 数据安全与个人信息保护

1. 双方仅在履行本协议所必需的范围内处理客户数据，并遵守适用的数据安全、网络安全和个人信息保护要求。
2. 数据类别、处理目的、存储位置、保存期限、访问权限、备份、删除和事件通知要求见附件二《数据处理与安全要求》；未明确前不得将客户数据用于公开演示、模型训练或向无关第三方披露。
3. 乙方应采取与项目风险相适应的访问控制、最小权限、传输与存储保护、日志审计和人员管理措施。
4. 发生疑似数据安全事件时，发现方应在[小时数]小时内通知另一方，并配合调查、控制、修复和依法报告。
5. 项目终止后，乙方按附件约定返还、迁移或删除客户数据，并在合理范围内提供处理证明。

## 第六条 保密

1. 一方从另一方获得且标明或依其性质应属保密的信息均为保密信息。
2. 接收方仅为履约目的使用保密信息，并仅向确有必要且承担同等保密义务的人员披露。
3. 已公开、接收方合法事先知悉、从无保密义务第三方合法获得或独立开发的信息不受本条限制。
4. 法律要求披露时，接收方应在允许范围内提前通知披露方并尽量缩小披露范围。
5. 保密期限：[填写]；商业秘密依法持续保护。

## 第七条 知识产权与开源软件

1. 开源软件继续适用 Apache License 2.0；本协议不减少甲方依该许可证已获得的权利，也不将购买企业服务作为使用开源代码的条件。
2. 双方在签约前已拥有的代码、工具、数据、文档、商标、方法和知识产权仍归原权利人所有。
3. 定制交付成果的权属及许可方式选择如下，并在订单中确认：[甲方所有／乙方所有并授予甲方永久使用权／双方约定的其他方式]。
4. 通用能力、非客户特有的工具和不含客户保密信息的改进归属：[填写]；任何公开发布不得包含客户数据或可识别的企业规则。
5. 客户数据及甲方专属业务知识归甲方或其合法权利人所有。
6. 项目名称、官方视觉和品牌使用应遵守仓库 `TRADEMARKS.md`；未经书面同意，不得暗示官方认证或合作背书。

## 第八条 人工决策与使用责任

1. 系统提供处理、分析和建议，不替代甲方采购员、法务、财务或其他责任人员的专业判断。
2. 分类、定标、合同、验收和项目收尾须由甲方通过对应质量 Gate 确认。
3. 市场价格仅供核验参考，不自动构成成本价、目标价、成交价或定标依据。
4. 甲方负责其采购活动、输入数据、最终决定和对外文件的合法性与准确性。

## 第九条 验收

1. 验收标准、测试数据、测试环境和证据见附件三《验收方案》；不得仅以主观感受替代约定指标。
2. 乙方提交交付物后，甲方应在[工作日]个工作日内完成验收并书面反馈。
3. 对不符合项，乙方在约定范围内修正后重新提交；新增需求按变更流程处理。
4. 甲方无正当理由逾期未反馈的处理方式：[视为验收／不视为验收，转入升级沟通]。

## 第十条 维护与服务级别

1. 免费质保期：[填写]，自[验收／上线]之日起计算。
2. 支持时间、渠道、故障等级、响应时间、恢复目标及排除项见附件四《服务级别说明》。
3. 第三方平台、模型、网络、硬件或甲方自行修改造成的问题，按约定的额外服务方式处理。
4. 安全更新、版本升级和重大变更应在受控环境验证后实施。

## 第十一条 陈述、保证与责任限制

1. 双方保证有权签署并履行本协议。
2. 乙方按约定标准提供企业服务，但不保证 AI 输出绝对无误、业务结果必然实现或第三方服务持续可用。
3. 除故意或重大过失、侵犯知识产权、违反保密义务、数据安全责任以及法律不得限制的责任外，一方在本协议项下的累计赔偿责任上限为：[合同已付费用／过去十二个月已付费用／其他金额]。
4. 在法律允许范围内，任何一方不对间接损失、可得利益损失或由对方未执行必要人工审核导致的损失承担责任；具体例外由双方结合适用法律确认。
5. 本条应由法律专业人士结合交易结构和适用法律重点审阅。

## 第十二条 变更、暂停与终止

1. 范围、周期、费用或数据处理方式的变更须通过书面变更单确认。
2. 一方严重违约且在收到通知后[天数]日内未补救，守约方可终止协议并追究责任。
3. 因违法风险、安全事件或逾期付款，守约方可在合理必要范围内暂停相关服务并及时通知。
4. 终止后，双方完成费用结算、交付物移交、账号停用、客户数据处理和保密义务延续。
