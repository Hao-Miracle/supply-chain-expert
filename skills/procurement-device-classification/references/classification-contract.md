# Classification contract

Inputs:

- Equipment name.
- Specification or model when available.
- A short technical remark when it changes the classification.

Outputs:

- System category and subcategory.
- Category code.
- Confidence score and label.
- Short evidence identifiers.
- Alternative candidates.
- Human-review flag.

Rule suggestions remain pending. A consumer may reuse confirmed history only when it owns the data, can trace the confirmation, and keeps that enterprise knowledge outside the public skill package.
